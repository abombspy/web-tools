# Phase 1 계산기 검증 체크리스트

> plan.md §6.3(계산 정확성 검증 절차)을 실행하기 위한 문서. 각 계산기를 구현한 뒤
> 배포 전에 아래 공식 출처와 동일한 입력값으로 대조하고, 경계값 테스트를 통과해야 한다.
> 계산기별로 실제 검증을 마치면 상태를 `[ ]` → `[x]`로 표시한다.

## 알바·직장인

- [x] **주휴수당 계산기** — 공식(소정근로시간÷40×8×시급, 40시간 상한), 지급 조건(15시간 이상 + 개근)을 근로기준법 시행령 제30조 해설 자료로 교차검증 완료(2026-09-20). 경계값 단위 테스트 `src/lib/calculators/weekly-holiday-pay.test.ts` 5개 통과. 최저임금 10,320원은 고용노동부 고시 제2025-47호로 검증 완료(`config/rates/labor.json`). 단, 고용노동부 노동포털의 대화형 계산기와 1:1 수치 대조는 아직 안 함(형식적 확인만).
- [x] **알바 월급 계산기** — 가산수당(연장·야간·휴일) 공식·5인 미만 사업장 예외를 근로기준법 제56조·시행령 별표1로 교차검증. 4대보험 근로자 부담률(국민연금 4.75%, 건강보험 3.595%, 장기요양 건강보험료의 13.14%, 고용보험 0.9%)과 월 60시간 미만 적용제외 원칙을 웹 검색으로 교차검증(2026-09-20, `config/rates/labor.json`에 출처 기록). 소득세는 정확한 간이세액표 대신 "106만원 미만 0원" 임계값만 반영하고 그 이상은 계산하지 않도록 스코프를 의도적으로 제한(사용자 확인). 경계값 단위 테스트 `src/lib/calculators/part-time-wage.test.ts` 8개 통과, SSR 렌더링 값도 수동 재계산으로 대조 완료. 단, 고용노동부 노동포털 계산기와 1:1 대조 및 근로소득 간이세액표 정식 반영은 아직 안 함(후속 작업).
- [x] **퇴사 시점 비교 계산기** — 퇴직금 공식(평균임금×30×계속근로일수/365, 3개월 역일수 기준 평균임금 산정)과 연차 발생 기준(1년 미만 최대 11일, 3년차부터 2년마다 가산, 최대 25일)을 웹 검색으로 교차검증(2026-09-20). 연차 계산 로직은 `annual-leave-days.ts`로 공용화(연차수당 계산기와 재사용 예정). 경계값 단위 테스트: `annual-leave-days.test.ts` 8개, `resignation-comparison.test.ts` 4개 통과(근속 364일 vs 365일 경계, 3년차 가산 경계 등). 스코프 제한: 평균임금은 최근 3개월 월급이 동일하다고 가정(상여금·연차수당 등 비정기 수입 미반영), 미사용 연차수당 금액은 계산하지 않고 일수만 표시. 고용노동부 계산기와 1:1 대조는 아직 안 함.
- [x] **연차수당 계산기** — 연차 발생 로직은 `annual-leave-days.ts`를 그대로 재사용(퇴사 시점 비교 계산기와 동일 검증). 1일 통상임금 산식(월급÷209×8, 209=（40+8)×52÷12)을 웹 검색으로 교차검증(2026-09-20). 경계값 단위 테스트 `annual-leave-pay.test.ts` 4개 통과(사용 연차가 발생 연차 초과 시 0일 하한 등). 스코프 제한: 주 40시간 정규직 기준(단시간근로자 비례 연차는 미반영, UI에 명시). 고용노동부 계산기와 1:1 대조는 아직 안 함.
- [x] **실업급여 모의 계산기** — 2026년 1일 상한액(68,100원), 하한액 공식(최저시급×8×80%=66,048원), 소정급여일수 표(고용보험법 별표1, 나이×가입기간 구간)를 웹 검색으로 교차검증(2026-09-20, `config/rates/labor.json`에 출처 기록). 경계값 단위 테스트 `unemployment-benefit.test.ts` 8개 통과(하한액/상한액 적용 경계, 가입기간 1년 미만 120일 고정, 만 50세 경계에서 소정급여일수 증가). 스코프 제한: 수급 자격(비자발적 이직 등) 자체는 판단하지 않고 "자격이 있다고 가정한 금액"만 계산(UI에 명시). 고용보험 홈페이지 모의계산과 1:1 대조는 아직 안 함.
- [x] **육아휴직 급여 계산기** — 2026년 구간별 지급률·상한액(1~3개월 100%/250만원, 4~6개월 100%/200만원, 7~12개월 80%/160만원)과 하한액(70만원), 사후지급금 폐지(2025년 1월~) 사실을 두 개의 독립 출처로 교차검증(2026-09-20). 경계값 단위 테스트 `parental-leave-pay.test.ts` 5개 통과(하한액 보장, 3→4개월 구간 전환 시 상한액 하락 케이스 포함). 스코프 제한: "6+6 부모육아휴직제" 특례는 별도 제도라 다루지 않음(UI에 명시). 고용보험 홈페이지 안내와 1:1 대조는 아직 안 함.

## 프리랜서·사업자

- [x] **3.3% 원천징수 역산 계산기** — 소득세 3% + 지방소득세(소득세의 10%) 구조는 법령상 고정값이라 별도 웹 조사 없이 구현(소득세법·지방세법). 지방소득세를 "세전의 0.3%"가 아니라 "소득세액의 10%"로 정확히 계산하도록 구현(원 단위 반올림 정합성). 세후→세전 역산은 근사치임을 명시. 경계값 단위 테스트 5개 통과(0원, 왕복 오차 ≤1원). SSR 기본값(세전 100만원→세후 967,000원) 렌더링 대조 완료.
- [x] **부가세 계산기** — 부가세율 10%는 수십 년째 고정된 법령값이라 별도 웹 조사 없이 구현(부가가치세법). 합계→공급가액 역산 시 "공급가액+부가세=합계"가 항상 정확히 성립하도록 구현(반올림 오차를 부가세 쪽으로 흡수). 경계값 단위 테스트 4개 통과. SSR 기본값(공급가액 100만원→합계 110만원) 렌더링 대조 완료.
- [x] **종합소득세 예상 계산기** — 종합소득세 누진세율표(8단계, 2023~2025년 귀속, 2026년 개정분 국세청 미게시)는 국세청 공식 페이지에서 직접 확인(2026-09-20). 업종 5개(1인미디어/저술가/학원강사/배달라이더/IT프리랜서)의 경비율은 여러 세무 블로그를 교차 검색해 확보했으나 기준 연도가 업종마다 다름(2019~2024년)과 **2026년 귀속 경비율은 2027년 4월에야 고시된다는 사실**을 확인 — `verified: false`로 명시하고 UI에도 안내함. 목록에 없는 업종은 사용자가 직접 경비율을 입력하도록 스코프를 제한(사용자 확인). 경계값 단위 테스트 6개 통과(단순/기준경비율 전환 경계, 세율 구간 경계, 과세표준 0원 하한). SSR 기본값(연매출 3천만원, 1인미디어, 기준경비율 적용) 렌더링 대조 완료(2,335,500원). 국세청 홈택스 모의계산과 1:1 대조는 아직 안 함.
- [x] **배달 라이더 순수익 계산기** — 플랫폼 수수료율을 하드코딩하지 않고 사용자 직접 입력으로 스코프를 제한해 데이터 조사 리스크(plan.md §6.4)를 원천 제거. 3.3% 원천징수는 기존 `withholding-tax-3-3.ts` 로직을 재사용(중복 구현 없음). 경계값 단위 테스트 4개 통과(수수료 0%, 비용>수입 시 음수 허용). SSR 기본값 렌더링 대조 완료(396,240원).
- [x] **스마트스토어·쿠팡 마진 계산기** — 카테고리별 수수료율을 하드코딩하지 않고 사용자 직접 입력으로 스코프를 제한(위와 동일 원칙, plan.md §6.4 리스크 해소). 판매가→마진율 정방향과 목표마진율→필요판매가 역방향 모두 지원. 경계값 단위 테스트 5개 통과(수수료 합+마진율이 100% 초과 시 에러, 판매가 0원 시 0으로 나누기 방지). SSR 기본값 렌더링 대조 완료(8,100원/27.0%).
- [x] **해외직구 관세 계산기** — 목록통관 면세한도(일반 150달러/미국발 200달러, 목록통관 배제품목 예외)와 "초과 시 전체 금액 과세(공제 없음)" 원칙을 웹 검색으로 교차검증(2026-09-20, `config/rates/tax.json`에 출처 기록). 스코프 제한: 관세율(품목별 HS코드)과 환율은 사용자 직접 입력, 개별소비세는 미반영(사용자 확인). 경계값 단위 테스트 6개 통과(면세한도 경계 1달러 차이로 과세 전환되는 절벽 효과, 미국발+목록통관제외 조합). SSR 기본값(140달러, 면세) 렌더링 대조 완료. 관세청 홈페이지 관세 계산기와 1:1 대조는 아직 안 함.

## 공통 절차

1. 계산기 구현 후, 위 공식 출처에 동일한 입력값을 넣어 결과가 일치하는지 확인한다.
2. 위에 나열된 경계값 케이스를 단위 테스트로 작성한다.
3. 두 항목 모두 통과해야 배포한다. 불일치가 있으면 plan.md §4의 계산 근거 설명을 먼저 재검토한다.
4. 매년 요율 개정 시(plan.md §6.6) 이 체크리스트를 다시 돈다.
